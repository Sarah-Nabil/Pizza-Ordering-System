### 🍕 Pizza Ordering System | C# Windows Forms

A **C# Windows Forms desktop application** that allows users to customize their pizza orders, calculate the total price dynamically, and confirm their selections through an interactive user interface.

**Key Features:**
- 🍕 Select pizza size: Small, Medium, or Large.
- 🧀 Customize toppings, including extra cheese, mushrooms, tomatoes, onions, olives, and green peppers.
- 🥖 Choose between thick and thin crust.
- 🏠 Select Eat In or Take Out.
- 💰 Calculate the total price based on the selected options.
- 🧾 Display an order summary that updates as selections change.
- ✅ Confirm orders and reset the form for a new order.

**Technologies:** C#, Windows Forms, Event-Driven Programming, Methods, Conditional Logic, and UI Controls.

This project helped me practice building interactive desktop applications, handling user events, and implementing reusable methods for price calculation and order management.
